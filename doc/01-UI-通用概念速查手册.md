# UI 通用概念速查手册（嵌入式视角）

本文档面向有嵌入式/RTOS 背景的开发者，建立通用 UI 心智模型，每个概念给出 **LVGL 对应实现** 以及 **嵌入式类比**，降低认知负担。

## 0. 一张图总览：这些概念怎么拼起来

```
┌──────────────────────────────────────────────────────────────┐
│                      用户操作层                                │
│   手指触控 / 鼠标点击 / 旋钮旋转 / 键盘按键                    │
└───────────────────────────┬──────────────────────────────────┘
```

## 1. 控件 (Widget / Control)

| 维度 | 说明 |
|---|---|
| **通用定义** | 屏幕上可交互或可显示的独立单元（按钮、滑块、文本框、图表…） |
| **LVGL 对应** | 一切皆 `lv_obj_t`。`lv_button_create()` / `lv_arc_create()` / `lv_chart_create()` 返回的都是 `lv_obj_t` 指针 |
| **嵌入式类比** | 类似一个「设备驱动结构体实例」——每个控件有自己的私有数据、操作函数集（class） |

**LVGL 源码入口**：
- 基类定义：`lvgl/src/core/lv_obj.h`
- 控件分类清单：`lvgl/docs/widgets/index.rst`

**本项目代码示例**（main.c）：
```c
g_temp_bar   = lv_bar_create(card_temp);       // Bar 控件
btn_save     = lv_button_create(btns);         // Button 控件
g_speed_arc  = lv_arc_create(card_spd);        // Arc 控件
```

## 2. 属性 (Property) + 样式 (Style)

这俩是配套关系——属性管"功能"，样式管"外观"。

### 2.1 属性

| 维度 | 说明 |
|---|---|
| **通用定义** | 控件自身的功能性参数（位置、大小、取值范围、当前值…） |
| **LVGL 对应** | `lv_obj_set_*` / `lv_obj_get_*` 系列；每个控件还有专属 API（如 `lv_slider_set_value()`） |
| **嵌入式类比** | 类似「设备寄存器」——每个值控制一个硬件行为 |

### 2.2 样式

| 维度 | 说明 |
|---|---|
| **通用定义** | 控件的视觉外观（颜色、边框、圆角、字体、内边距…） |
| **LVGL 对应** | `lv_style_set_*`（新建样式对象）/ `lv_obj_set_style_*`（直接往 obj 上写） |
| **嵌入式类比** | 类似「硬件配置结构体」——不改变功能，只改变"输出表现"（如 LED 颜色、数码管亮度） |

**关键区别（LVGL 面试级考点）**：
- `lv_slider_set_value(slider, 50, LV_ANIM_ON)` → **属性**（滑块停在 50%，功能性）
- `lv_obj_set_style_bg_color(slider, red, LV_PART_INDICATOR)` → **样式**（指示条变红，美观性）

**LVGL 源码入口**：
- 样式核心：`lvgl/src/misc/lv_style.c`
- 文档：`lvgl/docs/overview/style.rst` + `lvgl/docs/overview/style-props.rst`（所有样式属性清单）

**本项目代码对照**：
```c
// 属性（功能性）
lv_arc_set_range(g_speed_arc, 0, 100);            // main.c L287-L288
lv_bar_set_value(g_temp_bar, (int32_t)(t * 10), LV_ANIM_ON);

// 样式（美观性）
lv_obj_set_style_bg_color(card_temp, lv_color_hex(0xFFF8E1), 0);  // main.c L229
lv_obj_set_style_radius(card_temp, 8, 0);
lv_obj_set_style_text_font(g_temp_label, &lv_font_montserrat_24, 0);
```

## 3. 前景 / 后景（Z-Order / Layer）

| 维度 | 说明 |
|---|---|
| **通用定义** | 多个控件重叠时，谁在上面盖住谁 |
| **LVGL 对应** | 绘制顺序 + 全局 layer；没有显式 z-index 属性，靠创建顺序和特殊层控制 |
| **嵌入式类比** | 类似「多层 OLED 帧缓冲」——每层独立绘制，最后按顺序合成（或 2D 加速单元的图层合成） |

**LVGL 绘制顺序 3 条铁则**：

1. **兄弟控件**：**后创建的在上**（Z 更高）。同父下先创建 A 再创建 B → B 盖住 A。
2. **父子控件**：子控件永远在父控件**上面**（不可能被父盖住）。
3. **特殊全局层**（独立于屏幕控件树）：
   - `lv_layer_top()` → 全局顶层，用于弹窗、tooltip、悬浮按钮
   - `lv_layer_sys()` → 比 top 还高，用于鼠标光标、系统级加载遮罩

**验证小实验**：在同一个父 obj 里先创建红色按钮再创建蓝色按钮，两者重叠放 → 蓝色在上。调换创建顺序 → 红色在上。

## 4. 父-子关系 / 容器 (Parent-Child / Container)

| 维度 | 说明 |
|---|---|
| **通用定义** | 控件的嵌套包含关系。容器 = 能装其他控件的特殊控件 |
| **LVGL 对应** | **任何 `lv_obj_t` 都是容器**（基类自带容器能力）。`lv_xxx_create(parent, ...)` 第一个参数就是父 |
| **嵌入式类比** | 类似「设备树 / 总线结构」——I2C 总线是父，I2C 设备是子；父 enable / 移动，子一起跟着动 |

**4 条黄金规则**（所有 GUI 框架通用）：

| 规则 | 说明 | 本项目实例 |
|---|---|---|
| **父动子动** | 父控件坐标/尺寸改变，所有子控件按比例或相对偏移同步更新 | Tab 切换时，整个 tab_monitor 里的卡片一起移动 |
| **父裁剪子**（可配置） | 子控件超出父控件可视区域的部分默认不绘制（滚动就是基于这个） | `g_log_ta` 文字超过高度 → 被裁剪滚动显示 |
| **子相对父定位** | 子的 (0,0) = 父的「内容区左上角」（扣除 padding 后） | `ct_title` 在 `card_temp` 内 padding 后开始计算位置 |
| **样式部分继承** | 字体、文字颜色、文本对齐等"文本类样式"子不传就用父的 | header 里的 label 没显式设字体 → 继承自 screen 默认字体 |

**LVGL 源码入口**：`lvgl/src/core/lv_obj_tree.c`（`lv_obj_add` / `lv_obj_remove` / `lv_obj_delete` / 遍历树）

## 5. 坐标系 (Coordinate System)

| 维度 | 说明 |
|---|---|
| **通用定义** | 描述控件位置和尺寸的数学参考系 |
| **LVGL 规则** | **左上角为原点 (0,0)**，X 向右 +，Y 向下 +。和 LCD 帧缓冲扫描顺序完全一致 |
| **嵌入式类比** | 等同绝大多数 LCD 的 datasheet 约定——第一个像素就是左上角，逐行扫描 |

### LVGL 尺寸 / 位置的 3 种表示法

写界面时天天打交道，务必一次搞明白：

| 表示法 | 含义 | 适用场景 | 本项目实例 |
|---|---|---|---|
| **绝对像素数** | 直接写数字，单位 px | 固定尺寸图标、边框、控件最小高度 | `lv_obj_set_width(slider_speed, 320);` — main.c L409 |
| **百分比 `LV_PCT(x)`** | **相对于父的内容区**（扣除 padding 后），不是父的外边框！ | 响应式布局、撑满一行、按比例分栏 | `lv_obj_set_width(grid, LV_PCT(100));` — main.c L213 |
| **内容自适应 `LV_SIZE_CONTENT`** | 多大内容就多大尺寸，由子控件总边界 + padding 决定 | 标签、按钮、动态大小的容器 | `lv_obj_set_height(g_log_ta, LV_SIZE_CONTENT);` — main.c L440 |

### 盒模型 (Box Model)

`lvgl/docs/misc/boxmodel.png` 这张图建议看一眼。从内到外 4 层，任何尺寸/坐标都是相对某一层说的：

```
┌─────────────────────────────────────┐
│              margin (外边距)         │  和兄弟控件的间距
│  ┌───────────────────────────────┐  │
│  │      border (边框线)           │  │  有宽度、颜色、圆角
│  │  ┌─────────────────────────┐  │  │
│  │  │   padding (内边距)       │  │  │  border 和内容之间的留白
│  │  │  ┌───────────────────┐  │  │  │
│  │  │  │   content (内容)  │  │  │  │  子控件实际可绘制区
│  │  │  └───────────────────┘  │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

- `lv_obj_set_width(obj, 200)` = 设置 **content + padding + border** 三层总宽度（不包括 margin）
- `lv_obj_set_style_pad_all(obj, 10, 0)` = 往 padding 层加 10px 留白

## 6. 事件 (Event)

| 维度 | 说明 |
|---|---|
| **通用定义** | 用户操作（点击、滑动、值变…）或系统通知触发的回调机制 |
| **LVGL 对应** | `lv_event_t` 结构体 + `lv_obj_add_event_cb(obj, cb, filter, user_data)` 注册 |
| **嵌入式类比** | 完全等于「硬件中断 + ISR 回调」——中断源 = 事件类型 filter，ISR = 回调函数 cb，中断上下文 = user_data |

### 事件传递链（和中断优先级链神似）：

```
用户触控屏幕
    │
    ▼
输入设备 indev 的 read_cb 拿到 (x,y) 坐标
    │
    ▼
LVGL 做命中测试 (hit test)：从最顶层 obj 往下查
    找到 (x,y) 点上最上层的那个控件（比如某个按钮）
    │
    ▼
触发该 obj 上所有注册了该事件类型 filter 的回调
    │
    ├─ lv_event_get_target(e)  → 拿到"被点中的那个 obj"（中断源）
    ├─ lv_event_get_code(e)    → 拿到具体事件类型（CLICKED / PRESSING / …）
    ├─ lv_event_get_user_data(e) → 拿到注册时塞的 user_data（类似 ISR 参数）
    └─ 可选：开启 LV_OBJ_FLAG_EVENT_BUBBLE → 同事件冒泡给父控件（链式中断）
```

### 最常用事件类型速查：

| 事件 | 触发时机 | 典型用在 |
|---|---|---|
| `LV_EVENT_CLICKED` | 按下 + 松开，且中途没划出控件范围 | Button 点击确认 |
| `LV_EVENT_PRESSED` | 手指/鼠标刚按下去的瞬间 | 按钮按下效果（配合状态） |
| `LV_EVENT_VALUE_CHANGED` | 控件值有改变（滑块拖动、开关切换、下拉选中…） | Slider / Switch / Dropdown |
| `LV_EVENT_LONG_PRESSED` | 按住超过一定时间（默认 400ms） | 长按弹出菜单、长按删除 |
| `LV_EVENT_FOCUSED` / `DEFOCUSED` | 键盘/编码器切焦点时 | 高亮当前选中项 |
| `LV_EVENT_DRAW_PART_BEGIN` / `_END` | 控件的某个 part 绘制前后 | 自定义绘制（改图表曲线颜色） |

**本项目事件-回调映射表**：

| 用户操作 | 事件类型 | 回调函数 | 注册位置 |
|---|---|---|---|
| 拖 Power 开关 | `LV_EVENT_VALUE_CHANGED` | `switch_power_cb` | main.c L373 |
| 拖 Speed 滑块 | `LV_EVENT_VALUE_CHANGED` | `slider_speed_cb` | main.c L410 |
| 点 Save 按钮 | `LV_EVENT_CLICKED` | `btn_save_cb` | main.c L426 |
| 点 Clear Log 按钮 | `LV_EVENT_CLICKED` | `btn_reset_cb` | main.c L432 |
| 切换 Mode 下拉 | `LV_EVENT_VALUE_CHANGED` | `mode_dropdown_cb` | main.c L380 |
| 切 Alarm 开关 | `LV_EVENT_VALUE_CHANGED` | `switch_alarm_cb` | main.c L393 |

**LVGL 源码入口**：`lvgl/src/misc/lv_event.c`

## 7. 状态 (State)

| 维度 | 说明 |
|---|---|
| **通用定义** | 控件当前所处的模式（按下、禁用、选中…），状态会自动切换视觉样式 |
| **LVGL 对应** | `lv_state_t` 位图（多位可叠加）。用 `lv_obj_add_state()` / `lv_obj_remove_state()` / `lv_obj_has_state()` 操作 |
| **嵌入式类比** | 完全等于「设备状态寄存器」——每位一个 flag，可 OR 组合读取 |

### 最常用 5 个状态位

| 状态位 | 含义 | 典型场景 |
|---|---|---|
| `LV_STATE_DEFAULT` (=0) | 正常态，无任何特殊状态 | — |
| `LV_STATE_PRESSED` | 按下中（手指还没抬） | 按钮按下变色 |
| `LV_STATE_CHECKED` | 已勾选 / 已打开 | Switch=开、Checkbox=选、Toggle 按钮=激活 |
| `LV_STATE_DISABLED` | 禁用（灰化、不可点、不收事件） | 功能锁定、无权限 |
| `LV_STATE_FOCUSED` | 焦点高亮（键盘/编码器可操作） | 非触屏设备的选中指示 |

### 状态 × 样式 = 自动视觉切换（LVGL 杀手特性）

**不用你在回调里手改颜色**，只要注册时给每个状态配好样式，LVGL 自动切换：

```
按钮的样式表（概念示意）：
    DEFAULT 态  → bg_color = 蓝, radius = 8
    PRESSED 态  → bg_color = 深蓝     ← 用户按下瞬间自动套
    DISABLED 态 → bg_color = 灰       ← 调 lv_obj_add_state(DISABLED) 自动套
```

写法：`lv_obj_set_style_bg_color(btn, dark_blue, LV_STATE_PRESSED);`
第三个参数就是「哪个状态/Part 下生效」。

**本项目状态用法实例**：
```c
// switch_power_cb 中读 CHECKED 状态位（main.c L68-L81）
bool on = lv_obj_has_state(sw, LV_STATE_CHECKED);
if (on) { lv_led_on(g_led_power); ... }
```

## 8. 绘制 / 刷新周期 (Render / Refresh Cycle)

| 维度 | 说明 |
|---|---|
| **通用定义** | 把控件树 + 样式 → 像素点阵 → 写到物理屏幕的完整过程 |
| **LVGL 对应** | `lv_timer_handler()` 主循环 + `flush_cb` 后端 + 脏矩形机制 |
| **嵌入式类比** | 完全等于「LCD 控制器的 VSYNC 中断 + 帧缓冲搬运 DMA + 2D 加速」 |

### LVGL 刷新流水线（main() 的 while 循环在做的事）：

```c
while(1) {
    // 1. 处理所有 lv_timer_t：
    //    - 跑到期的定时器（用户的 1s 采集等）
    //    - 跑动画插值
    //    - 计算哪些 obj 变了 → 标记「脏矩形」
    //    返回：到下一个定时器到期还有多少 ms
    uint32_t t = lv_timer_handler();

    // 2. 等一会儿（或者立刻继续，取决于具体板子）
    //    在等待期间，lv_timer_handler 内部会调 display 的 flush_cb
    //    把脏区域像素推到屏幕
    lv_delay_ms(t);
}
```
（main.c L487-L490）

### 3 个嵌入式必懂关键词：

| 术语 | 含义 | 为什么重要 |
|---|---|---|
| **脏矩形 (Dirty Area)** | 只重绘变化的像素区域，不是全屏重绘 | MCU 上 CPU 带宽很紧张，全屏刷新会卡顿 |
| **帧缓冲策略** | Full / Partial / Direct 三种模式 | RAM 有限的 MCU（<32KB RAM）用 Partial 双小缓冲；带 SDRAM 的用 Full 双缓冲 |
| **flush_cb** | 把 LVGL 渲染好的像素"推"到屏幕的回调函数 | 移植到真实板子时你唯一要写的函数；通常 = DMA2D / SPI 刷屏 / LTDC 写层 |

**LVGL 源码入口**：
- 刷新核心：`lvgl/src/core/lv_refr.c`
- 软件渲染：`lvgl/src/draw/sw/lv_draw_sw.c`
- 文档：`lvgl/docs/porting/display.rst`

## 9. 输入设备 (Input Device / Indev)

| 维度 | 说明 |
|---|---|
| **通用定义** | 所有能让用户和 UI 交互的物理外设 |
| **LVGL 对应** | `lv_indev_t`，4 大类：`POINTER` / `KEYPAD` / `ENCODER` / `BUTTON` |
| **嵌入式类比** | 就是「BSP 输入层」——FT5406 触控芯片、按键 GPIO 中断、EC11 正交编码器、矩阵键盘驱动 |

### 4 类输入设备对应关系：

| LVGL 类型 | 典型硬件 | read_cb 里要填给 LVGL 的数据 |
|---|---|---|
| `LV_INDEV_TYPE_POINTER` | 电容触摸屏、鼠标 | `data->point.x / .y` + `data->state = PR/REL` |
| `LV_INDEV_TYPE_KEYPAD` | 物理键盘、矩阵键盘 | `data->key = XXX` + 方向键/Enter/Esc |
| `LV_INDEV_TYPE_ENCODER` | EC11 旋钮（带按压） | `data->enc_diff = +1/-1` + `data->state` 表示是否按下 |
| `LV_INDEV_TYPE_BUTTON` | 屏幕外物理按键（每个对应一个屏幕坐标） | `data->btn_id = N`（需另外配置每个 btn 对应屏幕点） |

**移植到板子时你要做的事**：写一个 `read_cb`，周期性从硬件寄存器（或 RT-Thread device）读值，按上面格式填。LVGL 帮你处理"命中测试 / 事件分发 / 焦点切换"等所有上层逻辑。

**本项目注册的输入设备**（SDL 模拟，见 main.c L481-L483）：
```c
lv_sdl_mouse_create();       // → POINTER 类
lv_sdl_keyboard_create();    // → KEYPAD 类
lv_sdl_mousewheel_create();  // → 辅助输入
```

**LVGL 源码入口**：
- 输入核心：`lvgl/src/indev/lv_indev.c`
- 文档：`lvgl/docs/porting/indev.rst`

## 10. 定时器 / 动画 (Timer / Animation)

两者都和"时间"有关，但分工不同，别混：

| 维度 | 定时器 `lv_timer_t` | 动画 `lv_anim_t` |
|---|---|---|
| **通用定义** | 周期执行的任务 | 某数值在起止之间按缓动函数平滑过渡 |
| **LVGL 机制** | 你写回调，回调里**自己改**控件的属性/状态 | 你给「起值、终值、时长、缓动」，LVGL **帮你算中间值**，每帧回调里你只负责把当前值"应用"到控件上 |
| **嵌入式类比** | = RT-Thread `rt_timer` / 软件定时 | = 硬件 PWM DAC 输出渐变 + 定时中断给下一个比较值 |
| **典型用在** | 传感器数据采集、心跳包、状态轮询 | 按钮按下缩放、页面切换过渡、进度条渐变、LED 呼吸 |

### 定时器使用三要素：

```c
// 1. 创建
lv_timer_t * t = lv_timer_create(my_cb, period_ms, user_data);

// 2. 回调（lv_timer_handler 内部会调）
static void my_cb(lv_timer_t * timer) {
    // timer->user_data = 创建时传的第三个参数
    // 在这里写业务逻辑，例如 lv_slider_set_value(...)
}

// 3. 控制（可选）
lv_timer_pause(t);    lv_timer_resume(t);
lv_timer_set_period(t, new_ms);
lv_timer_del(t);      // 注意不是 free
```

### 动画使用三要素（比定时器多一个"路径/缓动"的概念）：

```c
lv_anim_t a;
lv_anim_init(&a);
lv_anim_set_var(&a, slider);                       // 作用的对象
lv_anim_set_values(&a, 0, 100);                    // 起、终值
lv_anim_set_time(&a, 500);                         // 时长 500ms
lv_anim_set_path_cb(&a, lv_anim_path_ease_out);    // 缓动（先快后慢 = 自然）
lv_anim_set_exec_cb(&a, (lv_anim_exec_xcb_t)lv_slider_set_value_cb);  // 应用当前值
lv_anim_start(&a);
```

**本项目只用了定时器**（嵌入式典型用法）：
```c
lv_timer_create(timer_1s_cb, 1000, NULL);   // main.c L466
// 回调里每秒模拟采集温湿度 + 刷新仪表盘 + 推 Chart 数据
```

**LVGL 源码入口**：
- 定时器：`lvgl/src/misc/lv_anim.c` 顶部 `lv_timer_*` 系列
- 动画：同文件 `lv_anim_*` 系列
- 文档：`lvgl/docs/overview/timer.rst`（你现在打开的文件）
